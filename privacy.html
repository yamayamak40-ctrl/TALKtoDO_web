プライバシーポリシー

TALKtoDO  ·  最終更新日：2026年5月2日

01

取得する情報

本アプリは、以下の情報を取得・送信する場合があります。

（1）ユーザーが提供する情報

  • ユーザーが選択または共有したスクリーンショット画像
  • 画像に含まれるテキスト、予定、タスク、人物名、場所、日時などの情報
  • 解析結果として抽出された予定・ToDo情報

（2）アプリ利用に伴い取得される情報

  • アプリの表示言語およびロケール情報
  • Firebase 匿名認証 ID
  • 端末ごとのインストール ID

（3）課金・利用状況に関する情報

  • クレジット残高
  • 購入商品 ID、取引 ID
  • 解析枚数、処理日時
  • 利用した AI プロバイダ
  • 概算トークン数・コスト等の運用ログ
02

利用目的

取得した情報は、以下の目的で利用されます。

  • スクリーンショットの解析
  • 予定および ToDo の抽出
  • カレンダー追加機能およびタスク管理機能の提供
  • クレジット管理および購入処理
  • 不正利用の防止
  • 障害調査およびサービス改善
03

情報の保存および管理

  • 解析結果、履歴、ToDo、クレジット情報は Firebase Firestore 上に保存されます
  • スクリーンショット画像は解析のため外部 AI API へ送信されますが、本アプリのサーバー上には保存されません
  • 共有シート経由の画像は端末内または App Group 領域に一時保存され、解析後に削除されます
04

第三者サービスの利用

本アプリは、以下の第三者サービスを利用します。必要な範囲で情報が送信される場合があります。

Firebase / Google Cloud
認証、データベース、Cloud Functions、ログ管理
OpenAI
画像解析
Gemini / Google AI
画像解析に利用される場合があります
Apple
App Store 決済、カレンダー連携、アプリ配信
05

個人情報および機密情報の取り扱い

本アプリは、ユーザーが共有したスクリーンショットを解析するため、画像内に含まれる個人情報や機密情報も処理対象となる可能性があります。

・不要な個人情報や機密情報は事前にトリミングまたは除外してください
・共有された情報は解析のため外部 AI サービスに送信される場合があります

06

カレンダー連携について

  • カレンダーへの予定追加は、ユーザーの操作および明示的な権限許可に基づいて行われます
  • ユーザーの許可なしに予定が追加されることはありません
07

ユーザー識別について

  • 本アプリはアカウント登録を必要としません
  • Firebase 匿名認証 ID および端末 ID によりユーザーを識別します
08

課金およびクレジット

購入されたクレジットは、画像解析機能の利用に使用されます。

09

改訂

本ポリシーは必要に応じて変更される場合があります。重要な変更がある場合は、アプリ内または適切な方法で通知します。
