TALKtoDO（以下「本アプリ」）は、ユーザーのプライバシーを尊重し、本アプリにおけるユーザー情報の取り扱いについて、以下のとおり定めます。

第1条

取得する情報

本アプリは、サービス提供のため、以下の情報を取得、送信、保存する場合があります。

1. ユーザーが提供する情報

  • ユーザーが選択または共有したスクリーンショット画像
  • 画像に含まれるテキスト、予定、タスク、人物名、場所、日時、会話内容等
  • 解析結果として抽出された予定、ToDo、タスク、メモ等の情報
  • ユーザーが手入力で作成した ToDo、メモ、期限等の情報

2. アカウントおよび識別情報

  • Sign in with Apple により提供される認証情報
  • Firebase Authentication により生成されるユーザー ID
  • 端末ごとのインストール ID
  • アプリの表示言語、ロケール情報

3. 課金およびクレジットに関する情報

  • クレジット残高
  • 購入商品 ID
  • Apple App Store の取引 ID
  • 購入日時、購入状態、復元情報
  • クレジットの付与、消費、返却等の履歴

4. 利用状況および運用ログ

  • 解析枚数
  • 処理日時
  • 利用した AI プロバイダ
  • 概算トークン数、概算コスト
  • 処理時間、エラー情報、障害調査に必要なログ
第2条

利用目的

本アプリは、取得した情報を以下の目的で利用します。

  • スクリーンショット画像の解析
  • 予定、ToDo、タスク、日時、場所等の抽出
  • カレンダー追加機能の提供
  • ToDo 管理機能の提供
  • クレジット残高の管理
  • App Store 課金および購入処理の確認
  • 購入済みクレジットの復元
  • 無料クレジットの重複取得防止
  • 不正利用、濫用、過度な利用の防止
  • 障害調査、品質改善、サービス改善
  • ユーザーからのお問い合わせ対応
第3条

スクリーンショット画像の取り扱い

  1. 1.ユーザーが選択または共有したスクリーンショット画像は、解析のために外部 AI サービスへ送信される場合があります。
  2. 2.スクリーンショット画像は、TALKtoDO のサーバー上には永続的に保存されません。
  3. 3.共有シート経由で受け取った画像は、端末内または App Group 領域に一時的に保存される場合があります。
  4. 4.一時保存された画像は、解析完了後または不要になった時点で削除またはクリアされます。
  5. 5.ユーザーは、スクリーンショット内に個人情報、機密情報、第三者の情報が含まれる場合、その内容も解析対象として外部 AI サービスに送信される可能性があることを理解した上で利用するものとします。
  6. 6.不要な個人情報や機密情報が含まれる場合は、事前にトリミング、加工、除外した上で利用することを推奨します。
機密情報や第三者の個人情報を含む画像を共有する際は、事前のトリミングを推奨します。共有された画像は外部 AI サービスに送信される場合があります。
第4条

解析結果・ToDo・履歴の保存

本アプリは、以下の情報を Firebase Firestore に保存します。

  • 解析結果・予定候補
  • ToDo 情報・手入力された ToDo
  • 解析履歴
  • クレジット残高・クレジット取引履歴
  • 購入商品 ID、取引 ID
  • 利用状況および運用ログ
スクリーンショット画像そのものは、原則として Firestore には保存しません。
第5条

第三者サービスの利用

本アプリは、以下の第三者サービスを利用します。サービス提供に必要な範囲で情報が送信される場合があります。

Firebase / Google Cloud
認証、データ保存、Cloud Functions、Firestore、運用ログ、不正利用防止、障害調査等
OpenAI
スクリーンショット画像の解析、予定・ToDo 抽出等
Gemini / Google AI
スクリーンショット画像の解析、予定・ToDo 抽出等（利用される場合があります）
Apple
Sign in with Apple、App Store 課金、購入復元、カレンダー連携、アプリ配信等
第6条

Sign in with Apple について

  1. 1.本アプリでは、ユーザー認証のために Sign in with Apple を使用します。
  2. 2.Sign in with Apple により提供される情報は、ユーザー識別、アカウント管理、購入情報の紐付け、データ復元等の目的で利用されます。
  3. 3.ユーザーがメールアドレスを非公開にした場合、Apple が提供するプライベートリレー用メールアドレスが使用される場合があります。
  4. 4.本アプリは、ユーザーが Apple ID で管理する情報を、Apple の定める範囲を超えて取得することはありません。
第7条

カレンダー連携について

  1. 1.本アプリは、ユーザーの操作に基づき、解析結果から抽出された予定をカレンダーに追加する機能を提供します。
  2. 2.カレンダーへの追加は、ユーザーの明示的な操作および端末上の権限許可に基づいて行われます。
  3. 3.ユーザーの許可なく、カレンダーに予定を追加することはありません。
  4. 4.カレンダーに追加される内容は、ユーザーが確認・編集した上で登録することを推奨します。
第8条

課金・クレジット情報について

  1. 1.本アプリでは、App Store のアプリ内課金によりクレジットを購入できる場合があります。
  2. 2.購入されたクレジットは、スクリーンショット画像の解析に使用されます。
  3. 3.本アプリは、購入確認、クレジット付与、購入復元、不正利用防止のため、購入商品 ID、取引 ID、購入日時、クレジット残高、クレジット履歴等を保存します。
  4. 4.決済処理自体は Apple により行われ、当方がユーザーのクレジットカード情報等を取得することはありません。
第9条

不正利用防止

本アプリは、無料クレジットの重複取得、不正な購入処理、過度な利用、システムへの不正アクセス等を防止するため、以下の情報を利用・保存する場合があります。

  • Firebase Authentication のユーザー ID
  • Sign in with Apple に関連する識別情報
  • 端末ごとのインストール ID
  • クレジット付与履歴・購入履歴
  • 解析回数・利用状況ログ
アカウント削除後であっても、不正な無料クレジット再取得や不正利用防止のため、個人を直接特定しない形式または復元困難な形式で、必要最小限の識別情報を保持する場合があります。
第10条

情報の保存期間

  1. 1.解析結果、ToDo、クレジット情報、購入履歴等は、ユーザーが本アプリを利用するために必要な期間保存されます。
  2. 2.ユーザーがアカウント削除を行った場合、当方は、法令上必要な情報、不正利用防止、購入履歴確認、障害調査等に必要な情報を除き、合理的な期間内にユーザー情報を削除または匿名化します。
  3. 3.一時保存されたスクリーンショット画像は、解析完了後または不要になった時点で削除またはクリアされます。
第11条

アカウント削除

  1. 1.ユーザーは、本アプリ内の手続により、アカウント削除を申し出ることができます。
  2. 2.アカウント削除により、解析履歴、ToDo、クレジット残高等の利用データが削除される場合があります。
  3. 3.購入履歴、不正利用防止、法令遵守、会計上必要な情報等については、必要な範囲で保持される場合があります。
  4. 4.アカウント削除後も、Apple ID 側の購入履歴や App Store 上の取引情報は Apple の管理下に残る場合があります。
第12条

ユーザーの管理と注意事項

ユーザーは、本アプリの利用にあたり、以下に注意するものとします。

  • 第三者の個人情報や機密情報を含む画像を解析する場合は、必要に応じて事前に同意を取得してください。
  • 不要な個人情報や機密情報は、事前にトリミングまたは加工してください。
  • 解析結果は AI により生成されるため、正確性を保証するものではありません。
  • カレンダー登録や ToDo 保存を行う前に、内容を必ず確認してください。
第13条

安全管理

当方は、取得した情報について、漏えい、滅失、改ざん、不正アクセス等を防止するため、合理的な安全管理措置を講じます。ただし、インターネット通信、外部サービス、端末環境等に起因するリスクを完全に排除することはできません。

第14条

子どもの利用について

本アプリは、主として一般ユーザー向けに提供されるものであり、13 歳未満の児童を主な対象としていません。未成年者が本アプリを利用する場合は、保護者の同意を得た上で利用してください。

第15条

プライバシーポリシーの変更

当方は、必要に応じて本プライバシーポリシーを変更することがあります。重要な変更がある場合は、本アプリ内での表示、ウェブサイトへの掲載その他適切な方法により通知します。変更後のプライバシーポリシーは、本アプリ内またはウェブサイト上に掲載された時点で効力を生じるものとします。
